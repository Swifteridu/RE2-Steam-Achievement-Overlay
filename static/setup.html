Achievement file

Connect your Steam profile to load your Resident Evil 2 achievement progress.

Create one at steamcommunity.com/dev/apikey.
A custom profile URL (/id/...) or numeric SteamID64 both work.
Open overlay preview ↗

Before connecting

  1. Set your Steam profile to Public.
  2. Set Game details to Public in your Steam privacy settings.
  3. Create a Web API key and paste it above. Do not send the key to anyone.
Your API key is saved locally in this overlay folder's config.json. It is not sent to OBS viewers or stored by a third-party service. Do not share the config file.
