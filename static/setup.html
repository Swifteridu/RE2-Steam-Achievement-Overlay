Steam · Stream utility

Achievement tracker

Choose a Steam game, connect your profile and show your achievement progress in OBS.

Up to 3 results are shown.
You can find the AppID in the Steam Store page URL. The game must expose achievements through Steamworks.
Create one at steamcommunity.com/dev/apikey.
Open overlay preview ↗

Before connecting

  1. Set your Steam profile and Game details privacy to Public.
  2. Create a Steam Web API key and paste it above. Never send the key to anyone.
  3. Select a game with Steam achievements. Some games do not publish achievement data through the Steam API.
Your API key is saved locally in config.json. It is not sent to OBS viewers or stored by a third-party service. Do not share the config file.
